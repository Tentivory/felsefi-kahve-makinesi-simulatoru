# Felsefi Kahve Makinesi Simülatörü

## Bu Nedir?

Bu, dünyanın en ciddi, en bilimsel ve en gerekli projesidir. Kahve makinesi simüle eder ama kahve yapmaz. Bunun yerine varoluşsal sorular sorar, seni düşündürür ve belki de hayatın anlamını sorgulatır. Neden kahve içiyorsun? Neden bu kodu yazdın? Neden hala buradasın?

Gerçekten çalışır. Python ile yazıldı. Sonsuza kadar çalışabilir, dikkat et, RAM yemez ama zamanını yer.

## Nasıl Kullanılır?

1. Python yükle (eğer yoksa, kahve içmeden düşün).
2. `python kahve_makinesi.py` çalıştır.
3. Soruları oku, cevap verme, çünkü cevap yok.
4. Kahve bekleme, çıkmaz.

## Özellikler

- Sonsuz döngü (Ctrl+C ile çık, yoksa hayatın da sonsuz olur)
- Rastgele Türkçe felsefi sorular
- Abartılı ciddiyet
- Kahve yok, sadece düşünce

## Uyarı

Bu proje tıbbi tavsiye değildir. Kahve içmeyi unutma. Kod uykusuzluk yapabilir.
